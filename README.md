# SQL PORTFOLIO
A collection of SQL data analysis projects showcasing data cleaning, exploration, and insights.

## Projects

### [Motorcycle Retail Project](./motorcycle_retail_project/)
Comprehensive SQL analysis of a motorcycle retail business with exploratory data analysis, advanced analytics, and business intelligence.
- `1_motorcycle_retail_exploratory_analysis.sql` - Database exploration and key metrics
- `2_motorcycle_retail_advanced_analytics.sql` - Advanced analytics with SQL views and business recommendations
- **Key Insights:** 4+ years of growth data, customer segmentation, seasonal patterns, 7 strategic business recommendations
- **Analysis Includes:** Time-series analysis, product performance ranking, customer loyalty segmentation, revenue diversification opportunities

---

### [Global Layoffs Project](./global-layoffs-project/)
Analysis of global layoff trends with data cleaning and exploratory data analysis.
- `project_data_cleaning.sql` - Data cleaning and preparation
- `exploratory_data_analysis.sql` - EDA queries and insights
